# Code of Conduct

RepoLens follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our standard.** Be respectful, assume good faith, give and accept constructive feedback, and focus on what is best for the project and its users. Harassment, discrimination, personal attacks, doxxing and unwelcome sexual attention are never acceptable.

**Scope.** This applies in the project's issues, pull requests, discussions and any space where someone represents the project.

**Enforcement.** Maintainers may edit, hide or remove contributions, and may limit participation, when behaviour breaks these standards. To report a problem, use a private GitHub security advisory or contact the maintainer through their GitHub profile ([@TriSDec](https://github.com/TriSDec)). Reports are handled privately and in good faith.
